隐私政策

你的信息，如何被对待

我们尽量不收集、不存储你的数据。下面把本站用到的每一处数据处理说清楚，方便你判断要不要留下信息。

我们是怎么样的站点

HOUDA+ 是一个纯静态网站，托管于 Cloudflare Pages，不运营任何自有服务器，也不在站点本身存储访客数据。你在本站产生的数据，只会流向下面列出的第三方服务（且只用于对应功能）。

招新表单（金数据）

在「加入我们」页面填写的入群申请，由 金数据（jinshuju.net） 收集与存储，本站不接触、不留存这些字段。

  • 收集内容：昵称、联系方式（微信 / QQ / 邮箱）、想加入的社群、自我介绍（选填）。
  • 用途：仅用于与你联系、拉你入群；不会公开，也不会用于其他目的。
  • 管理：数据归金数据托管，你可随时要求删除自己的申请记录（方式见下方「你的权利与联系我们」）。

留言墙（Giscus）

留言墙由 Giscus 提供，内容实际发布在 GitHub Discussions，属于公开内容。

  • 你发布的留言、昵称会公开显示在站内与 GitHub，请不要填写真实姓名、电话等敏感信息。
  • 你可在对应 GitHub Discussion 中自行编辑或删除自己的留言。

站内搜索

站内搜索使用的检索索引随网站一同打包，不会把你的搜索词上传到任何服务器，本地即可完成检索。

IP 纯净度检测工具

该工具在你的浏览器本地完成检测，不记录、不存储你的 IP 地址，也不会把结果发往本站服务器。

字体与图标

本站界面字体（Plus Jakarta Sans）来自 Google Fonts，图标（Phosphor Icons）来自 jsDelivr CDN。加载这些资源时，相应服务商会按常规收到访问所需的网络请求信息（如 IP、User-Agent）。

网站托管与访问日志

本站部署在 Cloudflare Pages。作为托管方，Cloudflare 可能按其隐私政策记录标准的访问日志（如访问时间、IP、请求页面），用于安全防护与运行维护。我们不会用这些日志识别个人身份。

你的权利与联系我们

你有权了解、更正或删除与自己相关的数据：

  • 招新表单数据：通过站内留言墙或 GitHub Issues 提出删除申请，我们会向金数据申请删除。
  • 留言墙内容：可在 GitHub Discussions 自行管理。

如对本政策有疑问，也欢迎通过站内留言墙或 GitHub Issues 与我们联系。

本隐私政策最近更新于 2026 年 8 月。若站点功能调整，我们会同步更新本页。
