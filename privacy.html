一、概述与适用范围

HOUDA+（以下简称「本站」或「我们」）是一个完全开源的社区项目，站点本身为纯静态网站，源代码托管于 GitHub、经由 Cloudflare Pages 部署。我们高度重视每一位访客的隐私，并参照全球领先科技企业（如 Google、Apple、Microsoft）的隐私实践与国际化通行标准，制定本隐私政策（以下简称「本政策」），以清晰、透明的方式，向您说明本站所进行之信息处理活动的范围、方式、目的，以及您所享有的各项权利。

1.1 政策的生效

本政策自 2026 年 8 月起正式生效，适用于该日期之后您对站点的全部访问与使用行为。我们保留依据法律法规之变动或本站功能之调整，适时修订本政策之权利；修订后之版本将以本页所标注之更新日期为准，并取代先前版本之效力。

1.2 适用范围

本政策适用于通过 HOUDA+ 官方域名及其所承载之全部页面、功能与服务而进行的信息处理活动，涵盖访客浏览、留言发布、入群申请提交等情形。本站所接入之第三方服务（包括但不限于金数据、GitHub、Cloudflare）均受其各自隐私政策之约束，本政策仅就本站自身之处理行为作出说明，不涉及对该等第三方处理行为之约定。

1.3 本站的运营性质

本站为纯静态网站，部署于 Cloudflare Pages 平台，不运营任何自建服务器，亦不在网站自身基础设施之上存储任何访客个人信息。您在使用本站功能时所产生之数据，将依据功能需要流转至下述具备相应资质之第三方服务提供者，且仅供实现对应服务功能之目的使用。

二、我们收集的信息及其用途

我们秉持「最小必要」之原则收集信息，即仅收集为提供相应功能所必须之信息，不收集与功能实现无关之数据。以下逐项说明各功能所对应的信息类型、收集方式与使用目的。

2.1 入群申请信息（金数据）

当您通过「加入我们」页面提交入群申请时，您所填写之内容由 金数据（jinshuju.net） 负责收集与存储，本站不直接接触、亦不留存上述字段之任何副本。

  • 收集内容：昵称、联系方式（微信、QQ 或电子邮箱）、拟加入之社群、自我介绍（选填）。
  • 使用目的：仅用于与您取得联系并完成入群流程；不对外公开，亦不用于本目的以外之任何用途。
  • 处理依据：基于您主动提交申请之行为所形成之必要联络，以及您所作出之明示同意。

2.2 留言墙内容（Giscus / GitHub Discussions）

本站留言墙由 Giscus 提供技术支持，留言内容实际发布于 GitHub Discussions，属于公开可见之信息。

  • 您所发布之留言正文及所使用之昵称，将公开显示于本站与 GitHub 平台，敬请避免填写真实姓名、电话号码、住址等敏感个人信息。
  • 您可于对应之 GitHub Discussions 主题中，自行编辑或删除本人所发布之留言。

2.3 站内搜索

本站站内搜索所使用之检索索引随网站一并打包分发，不会将您的搜索词上传至任何服务器，检索过程于您的浏览器本地完成，我们无从获知您所检索之具体内容。

2.4 IP 纯净度检测工具

该工具于您的浏览器本地完成检测，不记录、不存储您的 IP 地址，亦不会将检测结果回传至本站服务器或任何第三方。

2.5 资源加载与访问日志

为本站界面之呈现，我们引用了来自 Google Fonts 之界面字体（Plus Jakarta Sans）与来自 jsDelivr CDN 之图标资源（Phosphor Icons）。当您的浏览器加载上述资源时，相应服务提供方将按通行技术惯例收到完成请求所必需之网络信息（如 IP 地址、User-Agent、访问时间）。此外，作为托管平台，Cloudflare 可能依据其隐私政策记录标准之访问日志，用于安全防护与运行维护。我们不会利用此类日志识别特定自然人之身份。

三、信息的共享与披露

我们重视您的信息安全，除下列情形外，不会向任何第三方提供您的信息。

3.1 受托与协作之第三方服务提供者

为向您提供完整之服务功能，本站依赖下列独立第三方服务，相关信息将依据既定目的流转至对应服务方：

  • 金数据（jinshuju.net）：接收并处理入群申请信息，详见本章 2.1 节。
  • GitHub / Giscus：接收并公开展示留言墙内容，详见本章 2.2 节。
  • Cloudflare, Inc.：作为网站托管与安全防护方，处理访问请求所必需之网络日志。
  • Google Fonts / jsDelivr：应资源加载请求，按通行惯例接收相应网络信息。

3.2 我们不会出售您的信息

我们不会出售、出租或交换您的个人信息以获取商业利益，亦不会将您的信息用于与所声明目的无关之营销或画像活动。

3.3 法定披露

在适用法律法规明确要求、司法机关或政府主管机关依法定程序调取，或为保护本站及用户之合法权益免受紧迫不法侵害之必要情形下，我们可能在法律所允许之范围内，向有权机关提供相关信息。

3.4 国际数据传输

由于本站所依托的部分第三方服务由位于不同国家或地区的实体运营（例如 GitHub 及其母公司 Microsoft、Cloudflare、Google Fonts 的运营主体均设在美国），您的信息在相应功能下可能被传输至您所在国家或地区以外的服务器进行处理。相关服务方依据其各自的隐私政策与所适用的数据保护法律（如适用）处理上述信息，我们亦不会将您的信息用于其声明目的之外的任何用途。

四、信息的存储与安全保障

4.1 存储原则

如前所述，本站自身不存储任何访客个人信息。您所提交之申请信息存储于金数据平台，留言内容存储于 GitHub 平台，其存储地点、期限与安全保护措施均由相应服务方依其隐私政策与服务条款予以负责。

4.2 安全措施

我们采取以下措施以降低信息风险：全站启用 HTTPS 加密传输，确保数据于网络传输过程中之保密性；对第三方服务之选用，优先考量其业内通行之安全合规水平；本站代码开源、可审计，便于接受社区监督。但请您理解，互联网环境不存在绝对安全之保证，任何措施均无法杜绝全部潜在风险。

4.3 信息保留期限

我们仅在实现收集目的所必须之期限内，或法律法规所要求之期限内处理您的信息。当您撤回同意、申请删除或相应功能终止时，我们将协调相关服务方及时停止处理并删除或匿名化相应信息，法律另有规定者除外。

五、Cookie 与同类技术

本站自身不设置任何第一方 Cookie，亦不借助 Cookie 进行用户追踪或行为画像。唯需说明者，您于浏览器中所作的主题偏好（深 / 浅色）将存储于您本地设备之浏览器存储空间（localStorage），用于下次访问时延续您的显示偏好，该信息留存于您的设备之上，不会上传至本站服务器。此外，前述第三方服务（如 GitHub、Google Fonts、Cloudflare）于提供功能或资源过程中，可能按其自身政策设置 Cookie 或同类技术，相关事宜请以其各自之隐私政策为准。

六、您所享有的权利

在适用之法律法规框架下，您对个人信息的处理享有如下权利，并可依据本节所述方式予以行使：

  • 知情权与访问权：您有权了解我们及所依托第三方如何处理您的信息，并可请求查阅与之相关的信息副本。
  • 更正与补充权：如您认为所留存之信息不准确或不完整，有权要求予以更正或补充。
  • 删除权（被遗忘权）：在满足相应条件时，您有权要求删除与您相关的个人信息。
  • 限制处理权：在争议处理等情形下，您有权要求我们暂停对您部分信息的处理。
  • 数据可携权：在技术上可行时，您有权以结构化、通用、机器可读的格式获取您提供给我们之信息，并移转至其他服务提供者。
  • 拒绝权：对于基于正当利益等基础开展之处理，您有权在符合法律规定的情形下提出异议。
  • 撤回同意权：对于基于您同意而开展之处理，您有权随时撤回该等同意，撤回不影响撤回前已进行处理的效力。

6.1 权利行使方式

您可通过以下途径行使上述权利：

  • 入群申请信息：请通过本站留言墙或 GitHub Issues 提出删除或更正申请，我们将据此向金数据发起相应处理。
  • 留言墙内容：您可于对应 GitHub Discussions 主题中自行管理、编辑或删除。
  • 本地主题偏好：您可随时于浏览器设置中清除本站相关数据，或切换主题以更新该偏好。

我们将在收到您之请求后，于法律法规所规定之合理期限内予以响应与处理。部分请求可能因涉及第三方服务而需相应服务方协同完成，届时我们将尽力协调。

七、未成年人保护

本站主要面向具备完全民事行为能力之用户，原则上不主动收集未成年人（未满十八周岁）之个人信息。若您为未成年人，请在监护人陪同与同意后使用本站；如我们发现在未获监护人同意之情形下收集了未成年人个人信息，将尽快采取删除等补救措施。监护人如对本节内容存有疑问，可通过本章第九节所述方式与我们联系。

八、本政策的变更

为适应法律法规之更新或本站服务之演进，我们可能不时修订本政策。修订后之版本将标注新的更新日期并发布于本页。对于涉及您权利之重大变更，我们将以本页公告等合理方式予以提示。除法律另有规定外，修订后的政策自发布之日起生效；您继续使用本站，即视为您已阅读并同意变更后之内容。

九、联系我们

如您对本政策之内容、我们的信息处理实践，或您所享有权利之行使存有任疑问、意见或诉求，欢迎通过以下渠道与我们取得联系：

  • 通过本站留言墙留言，我们将予以查阅与回应；
  • 通过本站在 GitHub 平台之 Issues 渠道提交咨询或请求。

我们重视您的每一条反馈，并将在合理可行之范围内尽快回复。对于涉及个人信息删除、更正等具体请求，请于留言或 Issue 中尽量提供可识别您身份之必要信息，以便我们准确核实与处理。

本隐私政策最近更新于 2026 年 8 月。若站点功能调整，我们将同步更新本页并标注新的生效日期。
