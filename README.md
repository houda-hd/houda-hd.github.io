## 🏛️ 项目简介
**HOUDA+ 官网** 是长沙霉粉联盟六群分支的官方网站，  
全称为「侯明昊碗慧通讯录互吃大学」。  

本项目基于 **GitHub Pages** 构建，  
用于发布更新公告、展示侯大文化与社区活动，  
同时作为视觉统一与轻量架构的实验平台。

**访问地址：**  
👉 [click me](https://houda.pages.dev)

---

## 🧩 功能特色
- **响应式布局**：自适应桌面端与移动端。  
- **视觉统一**：整体配色、字体与动画风格协调。  
- **公告系统**：记录每次版本更新与优化细节。  
- **高可维护性**：模块化结构、轻量部署。  
- **社区联动**：整合侯大文化地标与活动。

## ⚙️ 技术栈
| 技术 | 说明 |
|:--|:--|
| **HTML5 / CSS3** | 页面结构与样式 |
| **Tailwind CSS** | 快速响应式样式框架 |
| **JavaScript (Vanilla)** | 前端交互逻辑 |
| **Font Awesome 6 Free** | 图标系统支持 |
| **GitHub Pages** | 托管与自动部署平台 |
